# Small source portfolio for human review

The offline rights-packet command uses the existing source-research shortlist
and source-candidate schema. It does not register or activate any source.
Every generated proposal retains unknown permissions and requires an appointed,
source-scoped rights reviewer. This is preparation, not legal advice or approval.

| Priority candidate | Useful coverage | Evidence boundary / next decision |
|---|---|---|
| CISA KEV catalogue | Exploited vulnerabilities; structured identifiers and remediation dates | Historical catalogue-only CC0 evidence is recorded; current licence recheck returned HTTP 403. Reconfirm scope, attribution, retention and no endorsement. No blanket CISA article/image permission. |
| Ubuntu Security Notices | Software and cloud security | Official IPR policy was read on 2026-10-21. Its own licence does not establish a security-notice prose licence. Request the exact USN reuse/retention scope; prevent full descriptions entering a metadata-only adapter. |
| BD CERT proposal | Bangladesh security reporting | Existing candidate identity, endpoint and reuse terms remain NOT_VERIFIED. The website was inaccessible; a different CIRT domain is not an authenticated substitute. Human source identity and publisher contact are required. |

Official references: [KEV licence](https://www.cisa.gov/sites/default/files/licenses/kev/license.txt),
[Canonical IPR policy](https://canonical.com/legal/intellectual-property-policy),
[recorded BD CERT candidate](https://www.bdcert.gov.bd/).

Existing arXiv metadata and attributed Cloudflare documentation remain research
and reference material. They do not supply current-news, consumer hardware or
Bangladesh digital-policy coverage. OSV aggregation terms require per-origin
review; a software repository licence does not license all aggregated records.
AI, semiconductors, consumer technology and public-interest policy remain gaps;
this slice adds no unverified feed list to conceal them.

For each packet, a human must establish publisher identity, exact endpoint,
authentication/rate constraints, identifiers versus article text, image rights,
attribution, retention, AI processing, evidence date/version and licence scope.
RSS accessibility is not republication permission. Unknown AI submission stays
unknown and blocked. Use the existing signed owner/reviewer workflow for any
future decision; a completed packet or a historical archive is not approval.
