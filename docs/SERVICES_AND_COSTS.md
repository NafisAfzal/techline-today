# Services and predictable costs

Reviewed against provider documentation on 2026-10-14. This is a proposed configuration; accounts, billing and quotas have not been inspected or enabled. The default operational budget proposal is **USD 0/month**, with inference and analytics disabled. Usage caps are not a provider billing guarantee.

| Service | Purpose / requirement | Cost assumptions and bounds | Failure / disable |
|---|---|---|---|
| GitHub repository and standard Actions runner | Source control, checks and Python collection/build; required for proposed workflow | Standard public-repository runner minutes are free; storage is separate. GitHub Free includes 500 MB shared artifact/Packages storage and 10 GB repository cache storage. Four jobs/day (112–124/month); 30-minute job timeout. Rollback artifacts retain two days; failure traces three days. Production bundle is capped at 25 MiB, so eight retained bundles consume at most 200 MiB raw, before other artifacts/account use. | Keep `PRODUCTION_ENABLED=false`; no cron exists. Confirm account remaining storage and zero-spend controls before activation. Do not raise cache limits or use larger runners/paid services. |
| Cloudflare Workers Static Assets | Static delivery; required for proposed hosting | Static asset requests are free/unlimited. Free accounts permit 20,000 assets, each up to 25 MiB; project enforces an 18,000-asset margin. No dynamic Worker, KV, D1, R2 or AI binding is configured. | Disable publication and roll back assets. Adding runtime code requires a new cost/security review. |
| RSS/API publishers | Evidence collection; required | Public endpoints, bounded requests, no paid subscriptions. Availability and rate limits vary; respectful intervals/conditional requests apply. | Individual failures retain evidence; total failure blocks publication. Disable a registry source if terms or limits change. |
| AI / translation providers | Optional publication-time summaries/translations | **Disabled** by default; no models selected or live inference validated. Cost is unknown until exact provider/model/terms are approved. Call/token limits and a local quota ledger exist; production inference is rejected by the release gate even with a positive budget until model-specific cost enforcement and durable quota accounting are implemented and reviewed. | `PIPELINE_AI_ENABLED=false`; extractive summaries and labelled English fallback remain usable. |
| Off-machine versioned backup | Required operational safeguard before launch | Destination not provisioned. Owner-controlled encrypted storage may avoid an incremental subscription; cloud storage cannot be assumed free. Retention proposal: 14 daily + 8 weekly + 12 monthly snapshots. | Restore from a verified manifest into an empty workspace. A local copy or Actions cache does not meet durability. |
| Custom domain / analytics / monitoring | Optional | No domain purchase, analytics token or external monitoring configured. Costs/privacy depend on the selected service. Free `workers.dev` hosting is proposed. | Leave configuration blank; owner receives ordinary workflow failure notifications after approved setup. |

Sources: [GitHub hosted runners](https://docs.github.com/en/actions/reference/runners/github-hosted-runners), [Cloudflare static asset billing and limitations](https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/), [Workers platform limits](https://developers.cloudflare.com/workers/platform/limits/). Recheck current terms and the owner's account at approval; do not infer a paid provider price from a free-credit tracker.

The cache-policy mitigation must be reassessed by 2026-11-03 even if registry scans are clean. Dependency upgrades, extra runner jobs, storage, model calls or a custom domain require their own grounded operational review.

Current [GitHub billing](https://docs.github.com/en/billing/concepts/product-billing/github-actions) distinguishes free public runner time from storage allowances. Two-day retention and bundle size reduce pressure but cannot guarantee zero spend across other repositories or existing account consumption. Review actual billed storage; disable further uploads/publication if the free allowance cannot be maintained. A USD 0 service proposal is conditional on those account checks, not a billing guarantee.

This design builds on Actions and directly uploads static assets with Wrangler. It does not use Cloudflare Workers Builds or Pages builds. For comparison only, [Workers Builds Free](https://developers.cloudflare.com/workers/ci-cd/builds/limits-and-pricing/) currently offers 3,000 build minutes/month, one concurrent build and a 20-minute timeout; [Pages Free](https://developers.cloudflare.com/pages/platform/limits/) has separate build limits. Neither quota is consumed by the proposed external-build architecture. No unlimited deployment-frequency promise is inferred from unlimited static requests; rate-limit/API failures retain the previous edition and require backoff.
