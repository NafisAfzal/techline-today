# Monetization and Growth Roadmap

Design monetization seams now, keep them disabled in V1.

## Stage 0: portfolio/public utility

Free for everyone:
- daily concise feed;
- all categories;
- bookmarks on device;
- daily/weekly/monthly/yearly digests;
- original source links;
- model/freebie trackers.

Success metrics:
- returning users;
- source-link clickthrough;
- digest completion rate;
- bookmarks;
- Core Web Vitals;
- pipeline reliability.

## Stage 1: audience and newsletter

Optional:
- weekly email digest;
- topic subscriptions;
- public RSS feed generated by the platform;
- browser notification for only high-value selected events.

Do not send alerts for every story.

## Stage 2: affiliate/sponsorship

Possible revenue without harming core product:
- clearly labeled affiliate links for eligible devices/tools;
- clearly labeled sponsored placement separated from editorial ranking;
- newsletter sponsor blocks;
- tool directory partner pages.

Rules:
- sponsorship never changes evidence status;
- paid placement never silently enters `Top stories`;
- disclose affiliate status next to the link.

## Stage 3: Pro user features

Potential paid features:
- synchronized bookmarks;
- unlimited custom alerts/watchlists;
- `track this model/company/tool` timelines;
- advanced source filters;
- personal morning/evening digests;
- export to Markdown/Notion/CSV;
- historical search beyond free archive;
- API access with rate limits;
- team collections.

Do not paywall original source links.

## Stage 4: B2B/API

Potential product:
- structured technology-news API;
- model-release and free-credit change feed;
- webhook events;
- organization watchlists;
- embeddable widgets.

At this stage introduce:
- Worker API;
- D1/Postgres depending scale;
- durable queues/workflows;
- billing provider;
- audit logs;
- organization/user authorization.

## Architecture seams required from V1

- content repository interface;
- analytics events through a wrapper, not direct scattered calls;
- outbound-link component that can later add affiliate disclosure;
- feature flags;
- entitlement checks around future premium UI, defaulting to free;
- stable story IDs and API-friendly schemas.
