# Contributing

Use the locked Node/pnpm/Python/uv versions in the README. Run fixture mode for tests; fixtures are synthetic and must not be published. Keep the approved visual system and English/Bangla resource parity. Source-backed changes need evidence, bounded fetching and conservative unknown values.

Before a pull request, run the commands in [TESTING.md](docs/TESTING.md). Explain the problem, resulting behavior, validation and limitations. Add regressions for changed behavior; do not weaken existing assertions. Keep provider/deployment credentials out of code, logs and fixtures.
